# Java Arrays

A collection of Java practice programs covering **1D Arrays and 2D Arrays** concepts, traversal, indexing, searching, and basic array operations.

## 📚 Topics Covered

### 1D Arrays

- Array Indexing
- For Loop Traversal
- For-Each Loop
- Taking Input
- Find Minimum Value
- Find Maximum Value
- Calculate Sum
- Calculate Multiplication

### 2D Arrays

- 2D Array Indexing
- 2D Array Traversal
- Taking Input & Output
- Find Minimum Value
- Find Maximum Value
- Jagged Arrays
